# Socks5 proxy by transport Y.Board 
SOCKS5-прокси на Python, передающий TCP-трафик через Яндекс Доски. Работает анстейбл. Примерная скорость 5 mbps

## fast startik

```powershell
python -m pip install -r requirements.txt
```
сперва запускаем сервер
```powershell
python -m server.main
```
хэш доски находится в ссылке boards.yandex.ru/whiteboard/?hash=*hash_id*

=> копируем ключ, который выдал сервер после запуска. далее запускаем уже клиент
```powershell
python -m client.main
```
вставляем ранее выданный ключ

## приколы

| Поле | Значение по умолчанию | Значение |
|---|---:|---|
| object_chars | 10000 | Кол-во символов одного объекта|
| object_window | 128 | Незавершённых собственных полей |
| chunk_bytes | 16384 | Максимум чтения TCP, байт |
| stream_window | 32 | DATA/FIN без подтверждения на поток |
| send_interval | 0.005 | Минимальный интервал между пакетами |
| ack_window | 0 | Окно обязательных служебных ACK. 0 — не требовать |
| ack_timeout | 20 | Таймаут служебного ACK/метаданных|
| object_retry | 2 | Повтор объектов/ссылок/очистки |
| object_ttl | 120 | Предельное ожидание доставки/очистки |
| frame_retry | 5 | Повтор DATA/FIN |
| frame_retries | 6 | Максимум повторов DATA/FIN |
| connect_timeout | 20 | Таймаут открытия TCP |

| Поле | По умолчанию | Значение |
|---|---|---|
| guest_name | Имя + случайный суффикс | Создаётся один раз, затем сохраняется |
| state_dir | .tunnel-state | Папка журнала, относительно папки конфига |
| ws_url | Пусто | Автоопределение сокета, отличное от пустого принудительный выбор |
| cookies | Пусто | Гостевой вход - иначе cookie своей сессии |
| debug | false | Подробные логи |
| socks_host | 127.0.0.1 | Локальный адрес SOCKS (только клиент) |
| socks_port | 1080 | Порт SOCKS (только клиент) |
